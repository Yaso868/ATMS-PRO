ATMS PRO – SMART IMPORT ENGINE 14.6.0 ALPHA

1. Öffne ATMS PRO.
2. Tippe auf „Import“.
3. Wähle die originale Excel-, CSV-, TSV- oder ATMS-JSON-Datei.
4. Tippe auf „Planliste analysieren“.
5. Kontrolliere Importprofil, Tabellenblatt, Fahrten, Fahrer, Flüge und Hinweise.
6. Tippe auf „Geprüfte Fahrten übernehmen“.

DAS IMPORTPROFIL VERSTEHT
Preis | Uhrzeit | Von | Nach | Name | Firma | Flug ang. | Flug ausg. | Wg | Pers | Uhrzeit | Ort | Wg

DOPPELTE ÜBERSCHRIFTEN
- Uhrzeit 1 = Abholzeit
- Uhrzeit 2 = Flugzeit
- Wg 1 = Fahrzeug
- Wg 2 = Fahrer
