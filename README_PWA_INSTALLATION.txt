ATMS PRO PWA DEV 14.5.5 – Installation

WICHTIG:
Eine PWA kann nicht direkt aus dem Download-Ordner (file:// oder content://) installiert werden.
Der vollständige Ordner muss über HTTPS bereitgestellt werden.

SCHRITTE:
1. ZIP entpacken.
2. Den gesamten Ordner mit index.html, manifest.webmanifest, service-worker.js und icons hochladen.
3. Die erzeugte HTTPS-Adresse in Chrome öffnen.
4. In Chrome „App installieren“ oder „Zum Startbildschirm hinzufügen“ wählen.
5. ATMS PRO über das neue App-Symbol starten.
6. In Live-Dispo einen Fahrer wählen.
7. „Standort dieses Handys verwenden“ antippen und die Standortfreigabe erlauben.

Die GPS-Position dieses Handys wird nur dem aktuell ausgewählten Fahrer zugeordnet.
Ohne Routing-API werden keine echten Live-Verkehrszeiten berechnet.
