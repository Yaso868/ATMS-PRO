ATMS PRO – Planliste ohne Gemini importieren

1. ATMS PRO öffnen.
2. Unten auf „Import“ tippen.
3. „Planliste auswählen“ wählen.
4. XLSX, XLS, CSV, TSV oder JSON auswählen.
5. „Planliste analysieren“ tippen.
6. Vorschau und Hinweise kontrollieren.
7. „Geprüfte Fahrten übernehmen“ tippen.
8. Entscheiden, ob die bisherige Liste ersetzt oder zusammengeführt werden soll.

Erwartete Mindestspalten:
- Zeit / Uhrzeit / Abholzeit
- Abholort / Abholung / Pickup
- Ziel / Zielort / Destination

Optionale Spalten:
- Fahrer
- Datum
- Flugnummer
- Flugort
- Preis
- Personen / PAX
- Fahrzeug
- Firma
- Hinweise
- Telefon
