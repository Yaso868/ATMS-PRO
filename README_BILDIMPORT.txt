ATMS PRO – Bildimport Alpha

1. ATMS PRO über die GitHub-Pages-/HTTPS-Adresse öffnen.
2. Import öffnen.
3. „Bild oder Planliste auswählen“ antippen.
4. WhatsApp-JPG/PNG auswählen.
5. „Planliste analysieren“ antippen.
6. Während der OCR-Analyse geöffnet lassen. Auf dem Handy kann dies 30 Sekunden bis mehrere Minuten dauern.
7. Vorschau sorgfältig prüfen.
8. Erst bei korrekten Daten „Geprüfte Fahrten übernehmen“ antippen.

Für beste Ergebnisse:
- vollständige Tabelle im Querformat
- hohe Auflösung
- keine Markierungen oder zusätzlichen WhatsApp-Overlays
- keine starke Komprimierung
- Überschriften und Fahrer-Spalte vollständig sichtbar

Excel, CSV, TSV und JSON bleiben weiterhin nutzbar.
